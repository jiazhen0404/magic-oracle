# 線上抽不到的 40 支（愛情類）

盤點日期：2026-09-11

`data/love.json`、延伸籤內容與 2026-09-10 的改寫總表都有這 40 支，
但 `index.html` 的 `EMBEDDED_FORTUNES` 沒有——而那才是實際被抽到的資料來源
（`data/*.json` 從來不會被抓取，見 CLAUDE.md）。

後果有兩個：

1. 這 40 支從來沒有人抽到過
2. 對應的延伸籤內容已經寫好，但永遠賣不出去——抽不到就走不到付費頁

不是 2026-09-10 那次改寫造成的，是既有狀態。
使用者 2026-09-11 決定另案處理：該輪的內容替換只做線上實際存在的 130 支。

## 為什麼不順手補進去

補上等於擴大可抽池，抽籤結果的分佈會改變。而那一輪改版的驗收方式是
「看契合度的分數分佈往 4 移動」，中途擴池會讓改版前後的比較失去意義。
要補的話，等那一輪的觀察期結束、收滿 30 筆問卷之後再做。

## 補的時候要注意

- 唯一 ID 一個都不能變，付費端與 KV 裡的解鎖憑證都靠它
- 補完要重算 `jie`（= st ＋ rx ＋ fw ＋ sa，空格接起來）
- `index.html` 會變大，注意 build 之後的檔案大小
