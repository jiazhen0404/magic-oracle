# 文案需求 · 主篇導引句（一句話）

**要什麼**：一句話，接在既有文章某個小標的正下方，把讀者引導到同批新開的長尾頁。
**為什麼由人寫**：施工單 3-3 包一明訂「刪哪一段、連結放哪一句已經指定，
但接續的那句導引文字由人工／GPT 寫，Code 不要自己造句」。

---

## 背景

站上已有一篇主文：

```
網址　/articles/love/breakup/how-to-get-over-a-breakup/
標題　分手後怎麼走出來？不是逼自己忘記，而是把生活慢慢拿回來
```

同一批要新開一個長尾頁，專門回答「失戀多久」這個查詢：

```
網址　/articles/love/breakup/how-long-to-get-over-a-breakup/
標題　失戀多久才能走出來？沒有標準天數，但有可以觀察的變化
```

兩篇會打到同一個查詢，所以主篇要瘦身：把「談期限、公式、自責」那一段
整段刪掉（那正是新頁的主題），改成一句話引導過去。不處理的話等於
自己跟自己打對台，兩篇一起掉。

---

## 現況：主篇這一節長這樣

```
## 分手多久才算真的走出來？

### 不要用固定天數替自己的感情打分數
網路上流傳很多期限，說幾個月或者交往時間的一半就應該好了，這些數字沒有
可靠的依據。關係長度、分手原因、生活重疊的程度、身邊有沒有人支持，都會
影響復原速度。用公式檢查自己是不是「太久了」，通常只會多加一層自責。

### 比起不再想他，更值得觀察這些改變
（一份六項的清單，保留不動）
最後一項通常最晚出現，也最能說明事情正在往前走。
（專業協助提示，保留不動）
```

## 改完之後要長這樣

```
## 分手多久才算真的走出來？

★★★ 這裡放你要寫的那一句 ★★★

### 比起不再想他，更值得觀察這些改變
（以下全部不動）
```

也就是說：

- **刪除**：小標〈不要用固定天數替自己的感情打分數〉與它底下那一段
- **新增**：在 H2〈分手多久才算真的走出來？〉正下方加一句導引
- **不動**：六項清單、收尾句、專業協助提示、標題、網址、其餘所有段落

---

## 這一句的要求

1. **一句到兩句**，接在 H2 底下、清單之前，讀起來要順
2. **要含一個行內連結**，錨文用新頁的完整標題：
   〈失戀多久才能走出來？沒有標準天數，但有可以觀察的變化〉
3. **不要重述被刪掉那段的內容**（期限、公式、自責）——那是新頁的主題，
   在這裡重述就等於沒刪
4. 語氣照主篇既有的調性：平實、不說教、不給保證
5. 全形標點

## 參考：同一篇文章現有的句子語氣

> 你不需要證明自己已經不在乎，也不需要把那段時間從記憶裡挖掉。
> 記得一段關係，和繼續過自己的生活，可以同時存在。

> 最後一項通常最晚出現，也最能說明事情正在往前走。

---

## 交付方式

直接回一句話就好，例如：

```
如果你正在算日子，那件事本身值得單獨談——（連結錨文）。
這裡先看另一件更值得觀察的事。
```

（上面只是格式示範，不是建議用語。）

拿到之後我會完成主篇改造與新頁上稿，兩者同一次推上線——
主篇先刪、新頁還沒上的話，中間那段時間「失戀多久」在站上等於沒人回答。
