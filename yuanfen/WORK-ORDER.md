## 任務 0：讓線上版本更新　🔴 先做這個

### 問題

網頁執行的是 `index.html` 內嵌的引擎，**不是 `src/`**。只覆蓋 `src/*.js` 而沒有重新 build，改動完全不會生效。

### 步驟

```bash
cd yuanfen
npm run lint      # 檢查組合數 1356 全過 ＋ 全域名稱無衝突
npm run build     # 必須顯示：bundle 約 95000 bytes → index.html 已更新
```

先用瀏覽器開本機 `yuanfen/index.html`，輸入驗收基準組，確認出現「一見傾心」再推。

```bash
git add -A
git commit -m "fix: 六破判定、交叉柱比對、曖昧期敘事修正"
git push
```

推完開 `unfinished.tw/yuanfen/`，用 `Ctrl+Shift+R` 強制重新整理（Cloudflare 會快取 HTML）。

### 若本機 build 後仍是舊結果

`src/` 沒覆蓋成功。檢查：

```bash
grep -c "po:" src/copy.js          # 應 ≥ 2
grep -c "crossPairs" src/yuanfen.js # 應 ≥ 2
grep -c "magnetic" src/tempo.js     # 應 ≥ 2
```

任何一個是 0 就是檔案沒放進去。

### 若 build 報「注入後仍殘留 require()」

`src/` 有檔案在函式內寫了 `require()`。`build.js` 的正則只剝除行首的頂層引用，**所有 require 必須寫在檔案最上方**。

## 專案規則（三條，不能破）

**1. 不要手改 `index.html` 的 `<script>` 開頭那段。**
從 `<script>` 到 `/* ───── 介面 ───── */` 是 `npm run build` 產生的，會被覆蓋。改引擎或文案改 `src/`。介面註解**以下**的 UI 程式碼才是手寫的。

**2. 改文案必跑 `npm run lint`。**
1,356 個組合、六條語意規則。規則說明在 `docs/COPY-SPEC.md`。

**3. 生日永遠不離開瀏覽器。**
引擎是純函數。頁面上寫著「兩組生日不會被儲存，也不會離開你的裝置」——這是唯一無法被競品複製的差異。**接金流時訂單只帶分數與品項，不帶生日。**

## 架構：文字從哪裡來

五個軸各自獨立。理解這個才知道要改哪裡。

| 軸 | 檔案 | 決定什麼 |
|---|---|---|
| **格局** | `src/shape.js` | 順不順、對不對等 → 前三段敘事（10 種） |
| **節奏** | `src/tempo.js` | 怎麼開始的 → 第 02 段（8 種） |
| **主動方** | `src/initiator.js` | 誰先動心／誰先出手 → 第 03 段（5×3） |
| **相遇** | `src/encounter.js` | 在什麼場合遇上、多久才顯現 → 第 03 段 |
| **維度** | `src/copy.js` | 溫度／重量／長度各一段（9×5×9 key） |
| **風味** | `src/flavour.js` | 綁在命盤上的個人化句（日支 12／日干 10／納音 30） |

### 兩條不要改回去的邏輯

**分數不決定敘事。** 前三段由 `shape.js` 判讀盤面配置，不是由分數排名決定。實測有 10.9% 的情況「最低維度」與次低只差 0–2 分，那時候斷言「真正卡住你們的是溫度」是硬掰。差距不足 8 分時不指名短板，改說「盤上沒有明顯的短板」（34.5% 走這條）。

**交叉柱比對不能拿掉。** `src/yuanfen.js` 的 `crossPairs()` 比對非同位置的柱（A 日支 × B 年支⋯）。只比同柱會漏掉大部分關係——實測某組盤同柱只看到 2 組，交叉有 5 組。溫度分數會依交叉的合／沖修正 ±10。

## 常見的坑（都實際踩過）

**只覆蓋 `src/` 不 build**：網頁跑的是 `index.html` 內嵌的 bundle，改動不會生效。這是最常發生的一個。

**新增分類 key 沒補齊所有表**：加了 `po`（六破）之後，有 16 張分類表需要對應文案，漏掉 `basis.js` 一張就讓整個免費頁掛掉——而且 **node 端測試全過，只有跑瀏覽器才會爆**。加新 key 之後要跑全 key 覆蓋掃描。

**bundle 名稱衝突**：所有模組併到同一個作用域，新模組的頂層識別名要全域唯一。踩過兩次——`self-values.js` 的 `pick` 撞 `copy.js`、`initiator.js` 的 `HARSH` 撞 `shape.js`，兩次都是瀏覽器直接 SyntaxError 整支掛掉，**node 端完全測不出來**。`npm run lint` 現在會跑 `checkglobals.js` 自動掃描，加新模組前先跑一次。

**函式內的 require**：`build.js` 只剝除行首的頂層引用。`yearPillar` 裡寫 `require('./solar').lichun(y)` 會讓 `require` 帶進瀏覽器。

**運算子優先序**：`(seed ^ x) >>> 0 % arr.length` 是錯的，`%` 綁得比 `>>>` 緊。拆兩行。

**免費層分數不能受時辰影響**：`draw()` 刻意算兩次——免費那次不傳 `hour`。合併成一次的話，填了時辰的人會發現分數突然不一樣。

**語意重複抓不到**：`lint.js` 的 6-gram 只抓字面。`CONCEPTS` 概念群才抓得到「換句話說」。**規則檢查不能取代人眼——補完文案一定要抽三到五組完整輸出讀過。**

**否定句**：lint 的極性判斷要先剝掉「不會／不再／不是／沒有」開頭的子句，否則「不是爭吵，是各過各的」會被判成負面。

**檔名關鍵字批次刪檔**：曾用 `if 'star' in filename` 刪素材，把 `start-*.png` 一起刪了。要用完整比對。
