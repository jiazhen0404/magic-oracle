# 曖昧合盤

未完籤所（unfinished.tw）的雙人合盤產品，**專做曖昧期**。輸入兩個人的生日，算出緣分指數與三個維度，付費可讀 19 段完整報告。

## 為什麼限定曖昧

四種情境（曖昧／交往／分開／未定）都做過，但「說不上來」變成垃圾桶，「交往中」跨度從三個月到八年，兩者都只能寫得很中性——也就是最沒用的版本。

專做曖昧的代價是放棄交往中與分手後的客群，換來的是每一句話都能利。曖昧期是最焦慮、最想要答案、也最願意付錢的狀態，而且跟主站受眾（25–35 歲女性、愛情類佔八成）重疊度最高。

**其餘三種情境的 84 個 core 保留在 `src/copy.js`**，隨時可以開回來——`index.html` 的 `scene` 常數改掉即可。

## 開發流程

**改引擎或文案 → 改 `src/` 底下的檔案 → 跑 build → commit。**

```bash
npm run lint      # 文案模板檢查，必須全過
npm run build     # 併 bundle 並注回 index.html
```

`index.html` 開頭 `<script>` 到「介面」註解之間是自動產生的，**不要手改**——下次 build 會被覆蓋。介面註解以下的 UI 程式碼才是手寫的。

改分數常數之後跑 `npm run calibrate` 看分佈，目標平均 69–71。

## 部署

純靜態，沒有後端。計算全部在瀏覽器端完成，不送出任何生日資料。

Cloudflare Pages 直接指向這個資料夾即可，或放進主站的 `/yuanfen/` 路徑。

**`index.html` 與 `assets/` 必須一起更新。** 素材是上一版沒有的檔案時，只更新 HTML 會讓按鈕變成備援樣式。
