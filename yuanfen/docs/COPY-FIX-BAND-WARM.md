## 0　你需要知道的背景

這個產品輸入兩個人的生日，算出「緣分指數」與一份判讀。免費頁上會同時出現
好幾個獨立判斷，各由不同的模組產生：

| 軸 | 負責回答 | 例 |
|---|---|---|
| **分數帶** | 這段緣有多深、多有份量 | 緣滿／緣濃／**緣暖**／緣淡／緣薄／緣散 |
| **節奏** | 你們是怎麼開始的 | 一見傾心／日久深情／轟轟烈烈…（八種） |
| 機會 | 走到一起的機會多大 | 五階 |
| 主動方 | 誰先動心、誰先出手 | 五種 |
| 三個維度 | 溫度／重量／長度各自的狀況 | 各上千種句子 |

**每一軸只負責自己那一件事。** 這是這個產品的設計原則，寫在
`yuanfen/docs/DECISIONS.md`：「分數不決定敘事。」

---

## 1　問題

分數帶「緣暖」的判斷句**替節奏軸下了斷言**，於是跟節奏軸互相矛盾。

畫面上實際出現的樣子（相鄰兩段）：

> **節奏**：你們是**一開始就強烈吸引**的那一種。盤上有幾組交會得很深的地方，
> 那讓你在很早的階段就有一種「就是他了」的確定感——那個確定不是錯覺，它是有根據的。
>
> **摘要**：你們**不是一見面就燒起來**的那種，但也不會突然就沒了。

同一頁、相鄰兩段，一段說「一開始就強烈吸引」，下一段說「不是一見面就燒起來」。

### 發生率

抽樣 60,000 組真實盤面計算：

```
分數帶說「不是一見面就燒起來」而節奏判定是快速型：5,309 組 = 8.8%
其中「緣暖 × 一見傾心」單一組合就佔 5.1%（是第六常見的組合）
```

**不是偶發，是每十二個使用者就有一個會讀到。**

### 為什麼只有緣暖出問題

六個分數帶的判斷句我逐一檢查過，只有緣暖越界：

| 分數帶 | 判斷句 | 有沒有講「怎麼開始的」 |
|---|---|---|
| 緣滿 | 你們之間的順，是連旁人都看得出來的那種。這段緣不需要誰特別用力，它自己會往前走。 | 沒有 |
| 緣濃 | 你們大方向是合的，濃度也夠——這種關係走起來有實感，不會空。 | 沒有 |
| **緣暖** | **你們不是一見面就燒起來的那種，但也不會突然就沒了。** | **有 ← 問題在這** |
| 緣淡 | 你們沒有特別強的推力，也沒有明顯的擋。 | 沒有 |
| 緣薄 | 你們之間有一些天生就對不太上的地方，相處起來會比別人費力。 | 沒有 |
| 緣散 | 你們的節奏、需要、承受方式都不在同一條線上，這不是誰的錯，是先天就對沖。 | 沒有 |

其他五帶都只講「份量」，沒有碰「速度」。緣暖是唯一的例外。

## 2　要改的內容

### 2-1　判斷句（core）　🔴 必改

**現況：**

```
你們不是一見面就燒起來的那種，但也不會突然就沒了。
```

**要改成：** 只講「這段緣的份量與延續性」，**完全不提開始的快慢**。

參考其他五帶的寫法——它們講的是「順不順」「有沒有實感」「有沒有推力」
「合不合」「同不同步」，都沒有時間或速度的成分。

緣暖這一帶的意思是：**分數落在 70–79，關係穩、有延續性、但強度不是最高的那一級。**
把這個意思寫出來就好。

### 2-2　籤詩（poems）　🔴 五句要改四句

籤詩會與節奏標籤同時出現在畫面上，所以同樣不能講速度。
現況五句裡有四句在講「慢」：

| # | 現況 | 判定 |
|---|---|---|
| 1 | 不急的水走得最遠，因為它從不跟石頭爭。 | ✗ 「不急」是速度 |
| 2 | 水不會一次把路走完；它只是每天都往前一點。 | ✓ 講累積，沒講快慢，**可留** |
| 3 | 溫的東西留得久，燙的東西留不住手。 | ✗ 「燙／留不住手」暗示快＝不長久 |
| 4 | 慢慢來的關係沒有故事可以講，但走得久。 | ✗ 「慢慢來」是速度 |
| 5 | 一天暖一點，一年之後就不是同一種溫度了。 | ✗ 「一天暖一點」是速度 |

**要改的是 1、3、4、5 四句**，第 2 句可以留。

籤詩的風格：意象式、一到兩句、不直接說教。可以講「溫度」「留得住」「穩」
「不容易散」，但不要講「快慢」「先後」「一開始」。

### 2-3　建議句（close）　⚠️ 一句待判斷，非必改

第 3 句：

```
不用羨慕那些一見鍾情的人，他們要處理的問題你們早就處理完了。
```

這句提到「一見鍾情」，但講的是**別人**不是這一對，所以嚴格說不算越界。
不過當節奏判定剛好是「一見傾心」時，這句讀起來會有點怪
（等於在跟自己說「不用羨慕你自己」）。

**由你判斷要不要改。** 檢查程式刻意不擋這一句。

## 3　界線：不能出現的詞

改寫時，判斷句與籤詩**不可以出現**以下字詞——它們屬於別的軸：

```
節奏軸：  一見  燒起來  見面就  一拍即合  轟轟烈烈  忽冷忽熱
          似曾相識  日久  慢慢熟  怎麼開始  一開始就強烈
主動方：  先動心  先出手  誰先主動
機會軸：  走到一起的機會  成的機會  機會偏低  機會很高  翻盤
```

這份清單就是自動檢查用的字表，寫完會被逐字比對。

**注意**：「慢慢」本身沒有被列入禁用，因為它也可以形容累積而不是速度。
但如果整句的意思是在講「開始得慢」，那還是越界了——字表擋得住字面，
擋不住語意，這一層要靠人判斷。

## 4　驗收

改完之後，在 `yuanfen/` 目錄執行：

```bash
npm run lint
```

必須看到：

```
檢查組合數：1356
全部通過 ✓
```

目前執行會看到 **R7** 這一條紅字，那就是這份施工單要修的問題：

```
【R7】core 不得對其他軸下斷言
  · 總分帶/緣暖　core 講到【節奏】的「一見」
```

另外還有兩條既有規則會一起跑，改寫時要一併滿足：

- **R6**：同一組 open／core／close 之間不得有 6 字以上的重複片語
- **R3**：close 不得重述 core（共用三個以上的概念群就會被判定）

## 5　附錄：八種節奏長什麼樣

這是節奏軸的地盤，分數帶不要碰。列出來是讓你知道有哪些可能性——
**任何一種都可能與緣暖同時出現**，所以緣暖的文案必須對八種都成立。

| 節奏 | 開頭那句 |
|---|---|
| 一拍即合 | 你們是一開始就對上的那一種。 |
| 轟轟烈烈 | 你們是撞上的那一種。 |
| 一見傾心 | 你們是一開始就強烈吸引的那一種。 |
| 平淡如水 | 你們是淡的那一種。沒有一見鍾情，也沒有明顯的不對盤。 |
| 日久深情 | 你們是慢慢長出來的那一種。 |
| 相見恨晚 | 你們是合得來、但時機一直不太對的那一種。 |
| 似曾相識 | 你們是照鏡子的那一種。 |
| 忽冷忽熱 | 你們是反覆的那一種。 |

**這就是為什麼緣暖不能講速度**：同一個分數帶會配上「一見傾心」，
也會配上「日久深情」。任何速度的斷言，都一定有一半的情況是錯的。

## 附：另一批（優先度較低，不含在這份施工單）

同一次分析順便量到的重複度問題，供參考，**這份施工單不含這些**：

| 項目 | 現況 | 說明 |
|---|---|---|
| 節奏說明 | **只有 8 種** | 每 3 個使用者就有 1 個讀到同一句 |
| 機會說明 | **只有 5 種** | 同上 |
| 付費報告「什麼事，最容易讓你們就這樣停住？」 | **只有 3 種** | 付費 199 元的 24 段之一 |
| 另有五段付費內容 | 各只有 5 種 | |

對照組：三個維度各有 887／1,108／1,427 種句子，最常見的一句佔比不到 1%。
差別在於維度用「開場＋判斷＋收尾」三截組合並受 lint 六條規則管制，
後來新增的軸都只寫了一句話。

要處理的話另開一份施工單。
