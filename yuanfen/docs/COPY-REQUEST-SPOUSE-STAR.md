# 文案需求：配偶星「助或耗」

## 一分鐘理解這個產品

**未完籤所 · 曖昧緣分合盤**（unfinished.tw/yuanfen）。使用者輸入自己和曖昧對象的生日，
系統用八字合盤算出一份判讀。免費看得到摘要與三個維度，付費解鎖 24 段完整報告。

定位是「**在說不清楚的時刻，陪你把問題想清楚**」。使用者通常帶著一個具體的困惑而來：
他到底有沒有意思、我們差的是什麼、要不要再往前一步。

**不是算命，是把感覺翻譯成可以想的東西。**

## 這一軸要回答什麼

新增一個判讀軸：**這段關係對你，是滋養還是消耗。**

八字裡有「配偶星」——男命看財星、女命看官殺，代表「你會被什麼樣的人吸引」。
配合日主強弱（身強／身弱），傳統上會判斷這顆星對你是「喜」還是「忌」。

---

## ★ 最重要的一件事：不要把「忌」寫成「不好」

這是整份需求表的核心，寫歪了整批作廢。

實測 60,000 組命盤，在講得出結論的使用者裡：

```
身強（配偶星為喜）　30.8%
身弱（配偶星為忌）　69.2%
```

**近七成的使用者會落在「忌」這一邊。** 如果照傳統寫法翻譯成「你的正緣會拖累你」
或「你容易遇到消耗你的人」，等於七成的人抽完看到一句像詛咒的話。那不只體驗差，
而且**不誠實**——身弱財旺並不代表這個人命不好，它描述的是一種真實的關係狀態。

**要的翻譯方向是：**

| 不要寫 | 要寫 |
|---|---|
| 你的正緣會消耗你 | 這段關係會要你付出很多 |
| 你容易遇到不對的人 | 你被吸引的類型，本來就比較費力 |
| 財多身弱，主困 | 你想要的那種人，需要你拿出比平常更多的力氣 |
| 這段感情不利於你 | 這段關係的重量，比你現在的狀態重一點 |

**判準**：使用者讀完應該覺得「**難怪我這麼累**」，而不是「**原來我命不好**」。
前者是解釋，後者是判刑。這一軸存在的理由就是回答「為什麼我這麼費力」。

同理，身強那一邊也不要寫成「你很幸運」。那會讓另外七成相對更難受，
而且身強只是說「你撐得住」，不是說「你會順利」。

## 要寫的六個格子

每一格附了實際發生率，**請照比例分配力氣**。前兩格加起來超過一半的使用者。

### 格 1　身弱 × 配偶星有力　26%

你被吸引的類型很明確、存在感很強，但你目前的狀態撐這段關係會吃力。

要傳達：**吸引力是真的，吃力也是真的。** 兩件事同時成立，不互相否定。

### 格 2　身弱 × 配偶星不顯　29%

同樣吃力，但那個對象在你的盤上比較模糊——不是沒有，是不明顯。

要傳達：你要的東西自己也還沒完全講清楚。這一格的人往往是「說不上來喜歡他哪裡」。

### 格 3　身強 × 配偶星有力　11%

你撐得住，對象也清楚。

要傳達：條件是齊的，但**不要寫成保證**。齊不等於會成。

### 格 4　身強 × 配偶星不顯　12%

你撐得住，但你要的是什麼還沒成形。

要傳達：你有餘裕，問題不在能不能，在想不想清楚。

### 格 5　中和（強弱難判）　16%

**這一格不准下「助或耗」的斷言。**

程式算出來落在中和區，代表這張盤本來就難判。與其猜一個方向講得斬釘截鐵，
不如老實說這一層看不出來，轉而講別的。

要傳達：不是系統壞了，是這張盤剛好卡在中間——而那本身就是一種狀態
（你既不是特別撐得住，也不是特別吃力）。

**語氣要穩，不要道歉。** 敢說「看不出來」的判讀，才會讓人相信說「看得出來」的時候是真的。

### 格 6　命中無配偶星　7%

四柱裡找不到配偶星。

要傳達：這不代表沒有緣分，代表「你要的那種人」不在你原本的設定裡——
常見於「我也不知道自己喜歡什麼樣的人」。

**絕對不要寫成「你註定孤獨」或「晚婚」。**

## 硬規則（違反就退件）

這些來自 `RULES.md`，每一條都是實際踩過的坑。

### 1　不准暗示第三者

不可以寫「有人跟你競爭」「他身邊還有別人」「小心被搶走」，
或任何會讓讀者去查對方手機的句子。

**理由**：日柱只有 60 種，說錯了使用者會做出無法挽回的事。負責人 2026-09-11 確認維持禁止。

### 2　不准判人格缺陷

不可以寫「你太依賴」「你的問題是沒有主體性」這類。
判讀描述**狀態**，不評價**人格**。

### 3　機率語氣

「多半／通常／往往／容易」不是保守，是準確。

> ✓ 你多半會被那種一開始就很清楚自己要什麼的人吸引
> ✗ 你會被那種一開始就很清楚自己要什麼的人吸引

說中就是準；說不中，讀者只會覺得這次不準，不會覺得被騙。寫成斷言，錯了就是錯了。

### 4　不准跨軸下斷言

這一軸只能講「這段關係對你是滋養還是消耗」。**不可以碰**：

- 節奏（你們是怎麼開始的、一見鍾情還是日久生情）
- 主動方（誰先動心）
- 機會（走到一起的機率）
- 相遇場合

**理由**：報告裡各軸並列顯示，越界會在相鄰兩段當場矛盾。
實測過一次：分數帶寫了「你們不是一見面就燒起來的那種」，
而節奏軸判定「一見傾心」，8.8% 的使用者會同時讀到這兩句。

### 5　六個格子之間不准重複

同一份報告只會出現其中一格，但六格會被不同使用者讀到，
如果句型雷同，分享截圖時會被看出是罐頭。

**具體標準**：任兩格之間不得出現連續 6 個字以上相同。

## 語氣

參考現有文案的聲音（`src/copy.js`、`src/wrap.js`）：

- 講人話，不用術語。**不要出現「財星」「官殺」「身弱」「喜用神」這些字**——
  使用者看到的應該是關係的樣子，不是命理的名詞
- 第二人稱「你」，對方一律寫 `{B}`（程式會依使用者選擇替換成他／她／對方）
- 不安慰、不勸世、不下指導棋
- 句子可以短。不要為了文氣堆疊子句

**好的樣子**（取自現有文案）：

> 你們之間的東西是紮實的。不是最濃的那一級，但它有厚度——不容易被小事動搖，也不容易憑空消失。

**不好的樣子**：

> 這段感情雖然有些許阻礙，但只要你保持初心、勇敢面對，相信終將苦盡甘來。

## 交件格式

一個 JS 檔，`src/spouse-copy.js`，結構如下：

```js
const SPOUSE_COPY = {
  weak_strong:  { core: '…', poems: ['…', '…', '…'] },   // 格 1
  weak_faint:   { core: '…', poems: [...] },              // 格 2
  strong_strong:{ core: '…', poems: [...] },              // 格 3
  strong_faint: { core: '…', poems: [...] },              // 格 4
  mid:          { core: '…', poems: [...] },              // 格 5
  none:         { core: '…', poems: [...] },              // 格 6
};

module.exports = { SPOUSE_COPY };
```

**每格要交：**

| 欄位 | 長度 | 說明 |
|---|---|---|
| `core` | 60–90 字 | 判斷句。這是這一格的主文，會直接顯示 |
| `poems` | 3 句，每句 8–28 字 | 短句，隨機取一句顯示在 core 下方。像籤詩，不要像標語 |

**字數不含標點。** 籤詩範圍原本寫 12–20，那是憑感覺訂的，訂錯了——
現有已上線的 30 句籤詩實際落在 8–28 字，最短的是「火光會滅，餘溫不會。」（8 字）。
照 12 字退件等於逼人把好句子灌水。

**對方一律寫 `{B}`，不要寫死「他」或「她」。** 使用者可以選他／她／不指定，
寫死的話選「她」的人會讀到「他」。第一批交件有兩處寫死，已自動檢查守著。

`core` 遮起來之後，`poems` 應該還是完整的句子；
`poems` 遮起來之後，`core` 應該還是完整的判讀。兩者不互相依賴。

---

## 驗收標準

交件後我方會跑自動檢查，以下任一項不過就退回：

1. 六格兩兩之間沒有連續 6 字以上重複
2. 沒有出現命理術語（財星、官殺、身弱、身強、喜神、忌神、日主、四柱）
3. 沒有出現節奏／主動方／機會／相遇的斷言字眼
   （一見、燒起來、一拍即合、先動心、先出手、機會偏低…）
4. `core` 字數落在 60–90，`poems` 每句 12–20
5. 中和那一格（格 5）沒有下助或耗的斷言

另外會**人工讀一次**：把六格並排讀，確認沒有哪一格讀起來像在說「你命不好」。

## 附：不要做的延伸

以下有人提過，但這一批**不做**，不要主動加：

- 柱位（配偶星在年月日時哪一柱 → 什麼階段出現）→ 留給第二批
- 配偶星被合被沖 → 容易滑向第三者，暫不做
- 大運流年 → 本產品不排大運
- 婚期預測 → 產品定位是曖昧，不是婚配
