# 緣分指數 · 狀態與情境總表

寫文案之前要先把狀態列完，否則會發生兩件事：漏掉的狀態沒有對應文案，出現頻率極低的狀態卻花了同樣力氣寫。

| | 出現率 | 意義 |
|---|---|---|
| 緣暖 | **43.5%** | 主力 |

### 寫作資源分配

**八成的使用者會落在「緣暖」或「緣淡」，而且溫度／長度有近半是 `ping`。**

這代表：

- `ping` × 緣暖／緣淡 是最該寫深的組合，卻最容易被寫得敷衍（因為它「沒什麼特別」）
- 緣滿只有萬分之三會看到，但**不能不寫**——拿到的人一定會截圖分享
- 重量五種均分，任何一種寫壞都會影響兩成使用者

實際出現的三維度 × 分數帶組合：**548 種**（理論上限 1920，因為分數與 key 相關，不是獨立的）。

## 二、使用者情境（已實作）

**已於 v1.1 實作四種情境。** 以下保留當初的分析：原本所有文案都預設「已經在一起」。 「他在這段關係裡」「你們相處」這些句子，套在下面幾種情境會出戲：

| 情境 | 目前文案的問題 | 預估佔比 |
|---|---|---|
| **曖昧中** | 「這段關係裡」——還沒有關係 | 高 |
| **單戀／暗戀** | 「你們相處」——可能根本沒相處過 | 中 |
| **交往中** | 沒問題，目前寫的就是這個 | 高 |
| **分手後** | 「接下來會發生什麼」——語氣完全不同 | 中 |
| **已婚／同居** | 「他對長期關係看重什麼」——已經在長期關係裡了 | 低 |
| **朋友／同事** | 全部愛情語彙都不適用 | 低 |

你的 610 支籤在工作類已經做過同樣的事——分五個情境（迷惘中／求職中／轉職中／職場中／創業中），籤號 14–74 在五個情境各有一版。合盤應該沿用同一套邏輯。

### 建議收斂成四個情境

| 情境 | 涵蓋 | 稱謂與語氣調整 |
|---|---|---|
| **曖昧中** | 曖昧、剛認識、有好感 | 「你們之間」取代「這段關係裡」；不預設已有承諾 |
| **交往中** | 交往、同居、已婚 | 現行文案，不用改 |
| **分開了** | 分手後、冷淡期、失聯 | 改用過去式與「還有沒有可能」的框架 |
| **說不上來** | 單戀、朋友以上、複雜 | 最中性的措辭，避免所有關係定義 |

**不要做六個。** 已婚跟交往中的差別在文案上不大，朋友／同事的量太小，為它們各寫一版不划算。

### 實作成本

情境是**第五個維度**，但它不參與計分——只影響措辭。作法是每個 `core` 各寫四個情境版本：

```js
core: {
  曖昧:   '你們之間現在⋯',
  交往:   '這段關係裡⋯',      // 現有的
  分開:   '你們之間曾經⋯',
  未定:   '你和他之間⋯'
}
```

21 個 key × 4 情境 = 84 個 core（現在是 21 個）。open／close 大部分可共用，只有含關係預設的句子要分版。

**估計要新寫 63 個 core 加上約 40 句需要分版的 close。**

## 三、還沒處理的邊界狀態

| 狀態 | 現況 | 建議 |
|---|---|---|
| 同一天生日（雙方完全相同） | 會算出高分，文案讀起來像在講一個人 | 加一句特別的識別 |
| 相差 20 歲以上 | 沒有任何處理 | 年齡差不影響算法，但文案可以避開「同步」類措辭 |
| 生日在 2/3–2/5 | 年柱可能差一年 | 補立春精確表 |
| 未來的生日 | 目前只擋 1900–2100 | 應擋掉未來日期 |
| 雙方性別 | 完全不收 | 稱謂目前寫死「他」，同性伴侶會出戲 |

**性別那項值得優先處理。** 只要一個下拉（他／她／對方），影響的是整份報告的每一個代名詞，成本低但體感差很多。

---

## 四、建議順序

1. **性別稱謂**——一個下拉，改 `names` 參數就好，半天
2. **四個關係情境**——這是最大的一塊，但也是最能提升準確感的
3. **邊界狀態**——同生日、未來日期、立春表
4. 其餘文案擴充

第 2 項做完之前，不建議再擴充現有 key 的變體數量——因為情境分版會讓每一句都要重寫一次。

## 補記：四情境已完成（v1.1）

表單加入「你們現在的關係」下拉：交往中／曖昧中／已經分開／說不上來（預設交往中）。

`src/copy.js` 的 `core` 由字串改為物件：

```js
core: {
  交往: '這段關係裡，退讓比較多的是{A}⋯',
  曖昧: '你們之間，退讓比較多的是{A}。你會為了不打擾他而把話吞回去⋯',
  分開: '這段關係裡，退讓比較多的一直是{A}。你把話吞回去太多次⋯',
  未定: '你和他之間，退讓比較多的是{A}。你很在意會不會造成他的負擔⋯'
}
```

共 84 個 core。緣的溫度與緣的重量（13 個 key）四版全部另寫；緣的長度（8 個 key）因為用「這段緣」措辭，三個現在式情境共用，只有「分開」另寫過去式版本。

**情境不參與計分**——已驗證同一組生日在四個情境下分數完全相同。

`lint.js` 的窮舉迴圈已加入情境層，檢查組合數從 339 增至 **1,284**，全數通過。

### 實作時修掉的三處

- 溫度 `xing` 曖昧版與 close 字面撞「是說話的方式」→ 改為「講話的節奏」
- 長度 `same` 分開版與開場句同屬「未來」概念 → 改寫掉「之後」
- 重量 `bihe` 分開版被判語氣衝突 → 原因是 lint 的否定過濾漏了「**不是**」這個最常見的句式（「不是爭吵，是各過各的」被當成負面），已補進 `lint.js`

## 補記：緣的節奏（v1.2）

「合不合」與「怎麼開始的」是兩件事。格局（`shape.js`）講順不順、對不對等；節奏（`tempo.js`）講這段緣的樣子。

兩個人可以同樣 70 分、同樣 `onePoint` 格局，但一組是撞上的、一組是磨出來的——**這個差別讀者最有感，因為那正是她會拿來對照自己記憶的東西**。

| 節奏 | 判定 | 出現率 |
|---|---|---|
| 平淡如水 | 全平 | 37.3% |
| 日久深情 | 日支或年支三合 | 26.4% |
| 轟轟烈烈 | 日支六沖／相刑 | 20.0% |
| 一拍即合 | 日支六合 | 6.4% |
| 似曾相識 | 日支同支／自刑 | 4.5% |
| 忽冷忽熱 | 日支六害 | 2.7% |
| 相見恨晚 | 相處合但年支沖／刑 | 2.7% |

「相見恨晚」的判定優先於單看日支——合得來但節奏錯開，是一個獨立的處境，不該被歸進「一拍即合」。

### 出現在三個地方

- **免費結果頁**：等級名下方一個金框標籤（如「日久深情」）＋ 一句 intro
- **付費報告第 02 段**：完整的 intro ＋ arc ＋ note，約 180 字
- **分享卡**：等級名下方一行

分享卡加這一行的效果最直接——**「轟轟烈烈」「日久深情」這種詞本身就有傳播力**，比分數更容易讓人截圖。
